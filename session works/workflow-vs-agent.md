# Workflow vs Agent: Real User Requests

| No. | Real user request | Type | Why? |
| --- | --- | --- | --- |
| 1 | What is our company's annual leave policy? | Workflow | The system searches company documents and provides the answer. |
| 2 | How much money did we spend this month? | Workflow | The system retrieves financial data and calculates the total. |
| 3 | Find unused subscriptions, analyse their costs and recommend which ones we should cancel. | Agent | The AI needs to investigate multiple subscriptions, analyse usage and make recommendations. |
| 4 | Prepare a monthly business performance report using our financial data and project updates. | Agent | The AI needs to collect information from different sources, analyse it and prepare a report. |
| 5 | Check our project updates, identify delayed tasks and suggest what we should do next. | Agent | The AI needs to analyse project progress, identify problems and decide on useful next steps. |
