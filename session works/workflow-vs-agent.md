# Workflow vs Agent: Real User Requests

1. What is our company's annual leave policy?
   Type: Workflow
   Why: The system searches company documents and gives an answer.

2. How much money did we spend this month?
   Type: Workflow
   Why: The system collects financial data and calculates the total.

3. Find unused subscriptions, analyse their costs and recommend which ones to cancel.
   Type: Agent
   Why: The AI investigates subscriptions, analyses costs and makes recommendations.

4. Prepare a monthly business performance report using financial data and project updates.
   Type: Agent
   Why: The AI collects information from different sources, analyses it and prepares a report.

5. Check project updates, identify delayed tasks and suggest what to do next.
   Type: Agent
   Why: The AI analyses project progress, finds problems and suggests next steps.
