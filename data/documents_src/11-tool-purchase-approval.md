# Software Tool Purchase Approval

## Rule

A new software tool needs owner approval and must be registered in the subscription list before purchase.

## Steps

1. Describe the need and the expected benefit in a short request to the Operations Manager.
2. Check the subscription list: if an existing tool already does the job, use it or explain why a second tool is needed.
3. Where possible, run a free trial with the people who will use the tool.
4. Get the owner's approval.
5. Register the tool in the subscription list with plan, number of seats, monthly cost, billing day and the person responsible.
6. Only then buy the tool, using the company payment method. Do not use a personal card.

## Regular Review

- The Operations Manager reviews the subscription list every quarter.
- Tools with no active users for 3 months in a row are cancelled unless the owner decides otherwise.
- Price increases, duplicate charges and charges from tools that are not on the list are investigated.
